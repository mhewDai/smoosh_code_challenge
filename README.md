#Guideline
Build a data pipeline that scrapes or ingests concert/ticketing data and attributes users to the artists they engage with. The system should stitch together user touchpoints across multiple channels (concert clicks, ticket sales, merch purchases, social engagement, streaming activity) and calculate conversion funnels (view → click → purchase → stream). Deliverables include:

A clean schema for concerts, users, artists, and interactions

Attribution logic that assigns users to artists with scores

Conversion metrics per artist (CTR, ticket sales, merch orders, stream lift)

A simple API or dashboard to surface top insights

#Bonus
Figuring out conversions at each touch point, concert ticket sales, merch purchase, social posts Spotify listens etc.
